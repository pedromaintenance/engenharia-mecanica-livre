# Roadmap educacional

## F1 — Mapeamento

Mapear 10 cursos institucionais iniciais à [grade](../formacao/grade.md); vincular competências e pré-requisitos em vez de reproduzir as aulas. Revisar objetivos de cada curso na página original.

## F2 — Estruturar 6 trilhas

Engenharia generalista; mecânica de campo; confiabilidade; projeto; termofluidos; dados. Para cada uma: resultado de aprendizagem observável, avaliação diagnóstica, módulos, carga horária estimada com método explícito, bibliografia, exercício, avaliação final.

## F3 — Educação ativa

Cada unidade ganhará problema realista desidentificado ou fictício, modelo analítico e laboratório virtual. Criar banco de questões autorais com gradação de dificuldade e gabarito revisado.

## F4 — Plataforma de aprendizagem

Implementar progresso local opt-in, importação/exportação JSON versionado e acessibilidade mobile. Sem exigir conta pessoal para acessar material público. Evitar telemetria de usuários como condição para estudar.

## F5 — Avaliação

Rubricas objetivas e comparação de resultados com referência; distinguir aprovação pedagógica local de certificados de instituição externa. Critério de avanço: desempenho técnico, não tempo de tela.
