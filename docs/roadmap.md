# Roadmap executável

## P0 — Fundação (entrega v0.1)

- [x] Taxonomia inicial de domínios
- [x] Catálogo de fontes primárias e projetos livres, com política conservadora de reuso
- [x] Guia editorial, ficha de conhecimento e governança
- [x] CLI offline e calculadoras iniciais com testes
- [x] Site de documentação e workflow de qualidade
- [ ] Ativar GitHub Pages com fonte **GitHub Actions** nas configurações do repositório
- [ ] Validar a execução dos workflows após a primeira publicação

## P1 — Conhecimento (próximos ciclos)

- [ ] 50 fichas autorais de conceitos revisadas, incluindo exemplos dimensionais
- [ ] 100 recursos com licença efetivamente verificada por item
- [ ] 15 diagnósticos genéricos por sistema com árvore de hipóteses e inspeções seguras
- [ ] Trilhas completas em matemática, estática, resistência, termo, fluidos, elementos de máquinas e manutenção
- [ ] Revisão técnica e pedagógica por contribuidores

## P2 — Ferramentas técnicas

- [ ] Pint para dimensionalidade de entrada/saída
- [ ] CoolProp em módulo opcional para estados termodinâmicos
- [ ] Bibliotecas de fadiga, vibração, mancais e estatística de confiabilidade
- [ ] Modelos paramétricos no FreeCAD e exemplos independentes no CalculiX
- [ ] Pipelines reprodutíveis FEM/CFD com malhas e estudos de convergência
- [ ] Dashboards de RAM, Weibull, backlog e indicadores de manutenção, com dados fictícios

## P3 — Descoberta e pesquisa

- [ ] Adaptadores para API/OAI-PMH de acervos institucionais (sem copiar obras sem licença)
- [ ] Deduplicação DOI/ISBN e verificação periódica de links
- [ ] Busca híbrida, grafo de conceitos e citações por parágrafo
- [ ] API versionada de conhecimento e calculadoras
- [ ] Conjunto de avaliação contra respostas incorretas e fontes desatualizadas

## Critérios de avanço

Não medir progresso pela quantidade de PDFs. Medir **recursos verificáveis, cobertura conceitual, testes de cálculo, atualidade dos links, revisão técnica e capacidade de reprodução**.
